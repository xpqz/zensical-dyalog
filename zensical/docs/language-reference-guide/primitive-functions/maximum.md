# Maximum `R←X⌈Y`

```apl
R←X⌈Y
```
[Key to notation](../key-to-notation.md)

`Y` may be any numeric array.  `X` may be any numeric array.  `R` is numeric.  `R` is the larger of the numbers `X` and `Y`.

## Example
```apl
      ¯2.01 0.1 15.3 ⌈ ¯3.2 ¯1.1 22.7
¯2.01 0.1 22.7
```
