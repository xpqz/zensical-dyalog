# Expand First

```apl
R←X⍀Y
```
[Key to notation](../key-to-notation.md)

The form `R←X⍀Y` implies expansion along the first axis whereas the form `R←X\Y` implies expansion along the last axis (columns).  See [Expand](expand.md).
