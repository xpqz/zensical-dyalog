# Pi Times `R←○Y`

```apl
R←○Y
```
[Key to notation](../key-to-notation.md)

`Y` may be any numeric array. `R` is numeric. The value of `R` is the product of the mathematical constant *π=3.14159...* (Pi), and `Y`.

## Example
```apl
      ○0.5 1 2
1.570796327 3.141592654 6.283185307
 
      ○0J1
0J3.141592654

      *○0J1 ⍝ Euler
¯1
```
