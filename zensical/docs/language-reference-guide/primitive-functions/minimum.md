# Minimum `R←X⌊Y`

```apl
R←X⌊Y
```
[Key to notation](../key-to-notation.md)

`Y` may be any numeric array.  `X` may be any numeric array.  `R` is numeric.  `R` is the smaller of `X` and `Y`.

## Example
```apl
      ¯2.1 0.1 15.3 ⌊ ¯3.2 1 22
¯3.2 0.1 15.3
```
