# Same `R←⊣YR←⊢Y`

```apl
R←⊣YR←⊢Y
```
[Key to notation](../key-to-notation.md)

`Y` may be any array.

The result `R` is the argument `Y`.

## Examples
```apl
      ⊣'abc' 1 2 3
 abc  1 2 3
```
