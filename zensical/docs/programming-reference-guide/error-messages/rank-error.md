

# RANK ERROR `4`

```apl
4
```

This report is given when the rank of an argument or operand does not conform to the requirements of the function or operator, or the ranks of the arguments of a function do not conform.

## Example
```apl
      2 3 + 2 2⍴10 11 12 13
RANK ERROR
      2 3 + 2 2⍴10 11 12 13
      ^
```
