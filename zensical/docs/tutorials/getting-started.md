# Getting Started

Getting started with any new programming language can seem like a daunting task, and the Dyalog application development platform ships with enough features that you might appreciate some guidance to help you get started. The resources on this page are free of charge and aimed at APL novices.

## Community

APL has a thriving and enthusiastic community of users who are very happy to answer questions:

- Chat in [the APL Orchard](https://chat.stackexchange.com/rooms/52405/the-apl-orchard), a very active chat room
- Ask a question on [Stack Overflow](https://stackoverflow.com/questions/ask?tags=apl,dyalog) or the [r/apljk](https://www.reddit.com/r/apljk/) subreddit
- Post in [the Dyalog Forums](https://forums.dyalog.com/)
- Dyalog social media: [Facebook](https://www.facebook.com/DyalogAPL), [Instagram](https://www.instagram.com/dyalogapl/), [LinkedIn](https://www.linkedin.com/company/dyalog-ltd-), [Mastodon](https://mastodon.social/@dyalog)

## Basics

Resources to help you take your first APL steps:

- [Tips](https://www.dyalog.com/getting-started/tips.htm) is a page of "useful to know" suggestions from previous beginners.
- [Videos: Dyalog Basics](https://www.dyalog.com/getting-started/videos-dyalog-basics.htm) is a library of introductory videos.
- [*Mastering Dyalog APL*](https://www.dyalog.com/mastering-dyalog-apl.htm) by Bernard Legrand is a complete guide to the use of Dyalog, beginning with a thorough introduction to the APL programming language and progressing to worked examples. The book is available for purchase through [Amazon](https://www.amazon.co.uk/Mastering-Dyalog-APL-Complete-Introduction/dp/0956463800); a [free PDF download](https://www.dyalog.com/uploads/documents/MasteringDyalogAPL.pdf) and an [online revision](https://mastering.dyalog.com) (currently under development) are also available.
- [TryAPL](https://tryapl.org/) offers an interactive environment that allows users to play with simple APL expressions. Its [Learn tab](https://tryapl.org/?tab=learn) includes tutorials in which various scenarios are explored.
- [APL Wiki](https://aplwiki.com/wiki/) includes [simple examples](https://apl.wiki/Simple_examples) of APL in action (as well as some [more advanced ones](https://apl.wiki/Advanced_examples)).
- [APL Cultivation](https://apl.wiki/APL_Cultivation) is a series of chat lessons that were run through the [APL Orchard](https://aplwiki.com/wiki/APL_Orchard) chat room.
- [APL Course](https://course.dyalog.com/) is a self-study introduction to Dyalog with exercises.
- [APL Tutor](https://tutorial.dyalog.com/) is an online system that takes a complete novice through the terminology, conventions and functionality of APL (not specific to Dyalog's dialect). It looks a little dated but is a useful introduction.
- [APL Challenge](https://www.dyalog.com/apl-challenge.htm) is a free-to-enter quarterly competition aimed at new APLers, with questions designed to illustrate the use of functions and operators.
- APL Seeds is a series of annual events aimed at those who are just starting their APL journey. Materials and recordings are available from each: [APL Seeds '21](https://www.dyalog.com/apl-seeds-user-meetings/aplseeds21.htm), [APL Seeds '22](https://www.dyalog.com/apl-seeds-user-meetings/aplseeds22.htm), [APL Seeds '23](https://www.dyalog.com/apl-seeds-user-meetings/aplseeds23.htm), [APL Seeds '24](https://www.dyalog.com/apl-seeds-user-meetings/aplseeds24.htm).

## Advancing your knowledge

Resources to use as you become more familiar with APL:

- The complete Dyalog documentation set is on this site and regularly updated: start from the [reference guides](../language-reference-guide/index.md) or the [how-to guides](../how-to/index.md). Documents can also be [downloaded as PDFs](https://www.dyalog.com/documentation_200.htm), and a subset can be [purchased as printed manuals](https://www.lulu.com/spotlight/dyalog).
- A [library of Dyalog's webinars](https://aplwiki.com/wiki/Dyalog_webinar) covers materials as diverse as in-depth investigations of individual primitives, source code management and creating custom user commands.
- [APL Cart](https://aplcart.info/) is a searchable collection of approximately 4,000 short APL phrases intended for both beginners and professionals, with content provided by the community. It also features [a quiz](https://aplcart.info/quiz/) on a large sub-set of its contents.
- [APL Quest](https://problems.tryapl.org/) is a collection of 110 practice problems, complete with automated solution testing, sample solutions, and video walkthroughs.
- The [2016 Year Game](https://www.dyalog.com/2016-year-game.htm) provides an opportunity to practice your command of primitive functions and operators.
- The [Dyalog user meeting](https://www.dyalog.com/user-meetings/index.htm) provides a great opportunity to learn about Dyalog's newest features. [Recordings of the presentations](https://dyalog.tv/) (and downloadable materials) are available after each of these annual events.
- [APL Forge](https://forge.dyalog.com/) is a free-to-enter annual competition to create innovative open-source libraries and commercial applications using Dyalog APL.

## Development environment

Resources to help you with APL's Unicode symbols and environment:

- Entering APL symbols: the [Fonts and Keyboards](https://www.dyalog.com/apl-font-keyboard.htm) page includes free-to-download font files and installation instructions for different operating systems. Physical keyboards engraved with Dyalog glyphs are also available there.
- Using the Dyalog IDE: a set of [introductory videos](https://www.dyalog.com/getting-started/videos-dyalog-basics.htm) introduces some of the features. Full documentation is also available:
    - The Microsoft Windows IDE: [Dyalog for Microsoft Windows UI Guide](../windows-ui-guide/index.md)
    - The RIDE (default interface on macOS, optional interface on other platforms): [RIDE User Guide](https://dyalog.github.io/ride/latest/)

Once you have a working environment, the [tutorials](index.md) on this site take you through building something small that works, one step at a time.
