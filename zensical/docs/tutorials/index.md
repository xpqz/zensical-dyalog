# Tutorials

A tutorial teaches by doing. Each one takes you through building something small that works, one step at a time, and asks nothing of you but to follow along. Start here if you are new to Dyalog APL, or new to one of its interfaces.

## Learning the language

- [Getting started](getting-started.md): community, courses, videos and books for your first steps, and how to set up fonts, keyboards and the IDE.
- [TryAPL](https://tryapl.org): Dyalog APL in the browser, with guided lessons and nothing to install.
- [Mastering Dyalog APL](https://www.dyalog.com/mastering-dyalog-apl.htm) by Bernard Legrand: the full-length introduction to the language, free as a PDF, with an [online revision](https://mastering.dyalog.com) in progress.

## On this site

- [GUI Tutorial](../interface-guide/gui-tutorial/introduction.md): build a temperature converter with the Windows GUI objects, from an empty form to a finished application with menus, in eighteen short steps.
- [Writing ASP.NET Web Pages](../net-framework-interface-guide/writing-aspnet-webpages/index.md): your first APL web page, then page events, code-behind and converting an existing workspace.
- [Writing .NET Classes in APL](../net-interface-guide/writing-dotnet-classes/tutorial.md), and the same tutorial for the [.NET Framework](../net-framework-interface-guide/writing-dotnet-classes/tutorial.md).
- [A WPF Temperature Converter](../net-framework-interface-guide/windows-presentation-foundation/temperature-converter-tutorial.md): the GUI tutorial's application, built with Windows Presentation Foundation.
- [A Dual ActiveX Control](../interface-guide/activex-control/dual-control-tutorial.md): write an ActiveX control in APL.
- [Shared Code Files: a worked example](../shared-code-files-user-guide/worked-example.md): the shared code file I-beams, end to end.

Every page of these tutorials carries the *Tutorial* tag, so you can tell where you are when you arrive from a search.

## What belongs here

A tutorial has one goal, states what it assumes, and leaves the reader with a working result at every step. It does not explain options or alternatives; that is what the [how-to guides](../how-to/index.md) and the reference are for.
