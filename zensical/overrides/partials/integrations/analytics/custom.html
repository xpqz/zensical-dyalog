{#- First-party, cookie-less feedback transport. Zensical renders the "Was this page helpful?" widget (theme partial partials/feedback.html) whenever [project.extra.analytics.feedback] is set, but ships it hidden and inert: the only transport the theme provides is Google Analytics, which this project deliberately does not use. Setting provider = "custom" makes the theme include this partial and call __md_analytics() once the page is ready. We use that to unhide the widget and post each rating ourselves. Two transports, chosen by [project.extra.analytics].transport: beacon GET ?r=&p=&n=, as an Image. The workhorse: no CORS, no cookies. is "/feedback.gif"; Apache logs the request and tools/feedback_log.py reduces it to feedback.json. collector POST with page/rating form fields, via sendBeacon with a fetch fallback. Points at the local stub (tools/feedback_stub.py) for live demos and testing. A page is canonicalised by stripping any /./ version prefix. Clicks are handled per submit button, so SubmitEvent.submitter is never needed; the nonce stops caches swallowing repeat clicks. -#}
